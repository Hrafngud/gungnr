# Panel screenshots

Full-page captures of [panel.gungnr.org](https://panel.gungnr.org), taken on 2026-10-28 in Firefox with a 1600 px viewport width.

Sensitive text was replaced with neutral blocks and blurred in the browser before capture. This includes account identities and avatars, project names and paths, domains, IP addresses, integration identifiers, populated form values, environment contents, and diagnostic output. The PNG files contain only the resulting pixels. Nested scrolling regions were expanded to include their contents.

Slow reads were retried until their data loaded. For the updated captures, requests were allowed more time and serialized in the temporary browser, continuous metrics streams were paused, and finite animations were completed before capture. These adjustments only affected the capture browser; no application code, server configuration, or returned data was changed.

Only navigation and configuration dialogs were opened; no settings were saved, deployments started, or project operations submitted. Dialog images show the initial form state.
